## Strategic Goals

1. **Validate fast** — reach a go/no-go decision on any idea within 4 weeks.
2. **Build thin** — ship MVPs with the minimum surface area that tests the core assumption.
3. **Leverage AI** — automate research, code, copy, and ops wherever cost-effective.
4. **Compounding portfolio** — each project should share infrastructure or learnings with the next.

---

## Decision-Making Principles

- Decisions are logged in `decisions.md` with explicit reasoning and trade-offs.
- No project proceeds past ideation without a written decision entry.
- Kill criteria are defined before build begins, not after.
